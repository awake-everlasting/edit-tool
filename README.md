# ☁️ 하늘빛 사진첩

사진 최대 4장을 가로·세로로 이어 붙이고, 자막을 넣어 PNG로 저장하는 콜라주 도구입니다.
옛날 미니홈피 느낌의 하늘색 디자인이며, 사진은 서버로 올라가지 않고 브라우저 안에서만 처리됩니다.

## 기능
- 사진 칸의 `+`를 눌러 PC·휴대폰에서 사진 넣기 (끌어다 놓기 가능, 최대 4장)
- 사진 위에서 스크롤하면 확대/축소, 드래그하면 위치 이동 (휴대폰은 두 손가락 확대)
- **배치**: 가로/세로 방향, 칸 모양(1:1 · 4:5 · 16:9), 여백, 여백 색
- **글자**: 가로 모드에서 사진 하단 가운데에 자막 넣기 (내용 · 글씨체 · 크기 · 색)
- **저장**: 무작위 파일 이름(`collage_xxxxxxxxxx.png`)으로 PNG 저장

## 폴더 구조
```
├── index.html        # 페이지 구조
├── css/style.css     # 디자인
├── js/app.js         # 편집 기능
├── icons/favicon.svg # 아이콘
├── manifest.json     # 홈 화면 추가용 정보
└── .nojekyll         # GitHub Pages가 파일을 그대로 쓰도록 설정
```

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소를 만듭니다. (예: `sky-collage`)
2. 이 폴더의 파일을 **폴더 구조 그대로** 업로드합니다.
3. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/(root)`로 저장합니다.
4. 1~2분 뒤 `https://<내아이디>.github.io/sky-collage/` 에서 확인합니다.

## 참고
- 아이폰 HEIC 사진은 사파리 외 브라우저에서 열리지 않을 수 있어요. JPG로 바꿔서 넣어주세요.
- 글꼴은 Google Fonts(나눔고딕·주아·개구)와 jsDelivr(갈무리)에서 불러옵니다.
